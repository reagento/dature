Remote sources (`ConsulSource`, `EtcdSource`, `AwsSsmSource`, `AzureAppConfigSource`, `AzureKeyVaultSource`) no longer JSON-infer scalars above the schema root. Previously, string values were type-inferred before `prefix` navigated into the schema subtree, so any field below the document root (the normal case for Azure App Config/Key Vault key namespacing, and for Consul/etcd/SSM when `prefix` doesn't match the fetch path) could be silently corrupted — e.g. `Decimal`/long numeric strings narrowed to lossy floats, or strings starting with `[`/`{` mis-parsed as JSON.
